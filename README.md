## ⚽ Featured Project: HAJZI

> **HAJZI** (حجزي, "my booking") is a web platform for booking football fields online.

| Feature | Description |
|---|---|
| 🏟️ Field booking | Reserve **5v5** and **11v11** football fields in a few taps |
| 📅 Live availability | See open time slots in real time |
| 👥 For players & owners | Players book easily; field owners manage their schedules |
| 📱 Mobile-first | Designed for players booking from their phones |

**Status:** 🚧 In development
